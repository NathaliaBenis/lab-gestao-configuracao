# Laboratório de Gestão de Configuração Moderna com Git e GitHub

Este repositório foi desenvolvido como parte da disciplina de Engenharia de Software.

## Objetivo

Aplicar os principais conceitos de Gestão de Configuração Moderna utilizando Git e GitHub, incluindo:

- criação de repositórios;
- versionamento de código;
- utilização de branches;
- merge de funcionalidades;
- utilização do padrão Conventional Commits;
- integração entre repositório local e remoto.

## Estrutura

O projeto contém um exemplo simples de aplicação "Hello World", criado para demonstrar o fluxo completo de desenvolvimento utilizando Git.

## Tecnologias utilizadas

- Git
- GitHub
- Linguagem de programação (Python)
